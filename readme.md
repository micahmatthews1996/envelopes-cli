# Envelopes CLI

A command-line expense tracker written in Python.

Envelopes allows users to record, organize, search, and analyze their personal expenses using a simple command-line interface. Expense data is stored locally in a JSON file, making it lightweight and easy to use.

---

## Features

- Add expenses
- View all expenses
- Edit existing expenses
- Delete expenses
- Search expenses by keyword
-Search Expenses by range
- Sort expenses
    - Newest
    - Oldest
    - Highest amount
    - Lowest amount
    - Category
- Expense summary report
- Category report
- Automatic JSON data storage
- Input validation
