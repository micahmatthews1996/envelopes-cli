# 💰 Envelopes CLI

Envelopes CLI is a command-line budgeting application built in Python.

Originally created as a simple expense tracker, the project has evolved into a full budgeting application that allows users to organize expenses, create custom categories, set budgets, and monitor spending.

This project is part of my software engineering portfolio as I work toward becoming an Android Developer.

---

## Features

### Expense Management

- Add expenses
- Edit expenses
- Delete expenses
- View all expenses
- Search expenses
- Sort expenses
- Expense reports

### Category Management

- Create custom categories
- Rename categories
- Delete unused categories
- Protect categories that are currently in use

### Budget Management

- Create budgets
- Edit budgets
- Delete budgets
- Budget summaries
- Remaining budget calculations
- Over-budget detection

### Dashboard

- Total expenses
- Total budget
- Remaining budget
- Categories over budget
- Recent expenses
